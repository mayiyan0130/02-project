【2026-04-23 硬规则覆盖说明】

以下几条为后续讨论后确认的新硬规则，优先级高于本提取稿中较早的旧表述：

1. 位分系统现已改为“声望决定应有位分”，月结算时实际位分向应有位分推进，自然晋升与自然降位每月最多均为2级。
2. “未侍寝不能晋升”已废止。未侍寝角色仍可通过宴会、怀孕、生子、朝堂经营、协理六宫调位等方式增加声望并提高位分。
3. 若角色声望小于0，则直接进入冷宫；若为当前皇帝真爱值最高的妃子，则处罚事件结算后声望保底为100。
4. 皇贵妃位的新设条件现为：无皇后；或皇后健康小于400且持续3月；或皇后宠爱小于20且持续半年。
5. 协理六宫最多1人，每3个月可对位分低于自己的妃嫔进行一次最多2级的调位，并由宫女娇娇统一通报。
6. 生母为和亲公主/异国贡女的孩子默认不得立为储君，仅尘缘夙错线路例外。
7. 皇后恢复后，已在位皇贵妃不会被系统自动撤位。
8. 皇帝系统现采用固定公式：心情影响独寝、册封、养心殿裁断；真心值影响夜晚权重、御书房带回、求情宽判与受罚保底。
9. 生产后与流产后统一加入3个月生育冷却期；冷却期内即使侍寝也不会怀孕。
10. 玩家主动造谣扣福德5，主动下毒扣福德10；宝华殿为生育祈福每次加福德3。
11. 冷宫改为两条路径：宫斗/惩处导致声望小于0时立刻进入；自然声望连续两月小于-50时进入。
12. “福德为负”和“永久不孕”现已拆分，永久不孕由隐藏状态单独控制。
13. 侍寝中的“美言 / 诉苦 / 抹黑”现独立于宫斗系统：玩家可在侍寝时对交好妃子美言或对交恶妃子抹黑，目标宠爱 `±3~5`；此行为不计为主动宫斗，不扣福德，不进入调查。
14. 若当旬为其他妃嫔侍寝：交好妃子有80%概率为玩家美言，使玩家宠爱 `+3~5`；交恶妃子有20%概率向皇帝抹黑玩家，使玩家宠爱 `-3~5`。侍寝兴致达到100时，额外增加10声望。
15. 个人事务中的案件干预现统一改为 `20 银两 -> 5 点嫌疑变化`；若案件已锁定陷害妃嫔，玩家可持续追加其嫌疑，达到 `100` 即定罪。
16. 旁观案件的纪事干预也统一改为 `20 银两 -> ±5 嫌疑`，允许重复操作直到结案或银两不足。
17. 月度宫务开销改为按基础月俸比例计算：基础宫务 `20%`，高宠额外宫务 `10%`。
18. 家族线新增父亲官职月度声望加成与季度波动；入宫前 `6` 个月父亲官职不会降位。
19. 自然冷宫现改为“连续两月声望低于 `-50`”；事件导致声望低于 `0` 时立刻进冷宫。
20. 协理六宫 / 皇贵妃 / 皇后每年固定支出 `260` 处理节庆。
21. 后期权力路线新增 `2000 / 4000 / 6000` 三档大额朝堂事件，可获得虎符并提高夺位成功率。
22. 绣品 / 字画 / 补品统一按绿色、蓝色、紫色、红色四档品质区分；补品可送礼或自用，固定提供健康 `+20 / +40 / +60 / +80`，并额外提供容貌 `+5 / +10 / +15 / +20`。
23. 自定义剧情妃需保留系统接口：玩家可通过召见娇娇提交自由描述或结构化字段，下旬由娇娇通报其以家族举荐 / 和亲 / 外邦进献 / 宫女抬位等合理方式入宫；AI只负责草案解析与剧情文本，数值与合法性由系统硬校验。
24. 后期容貌 / 气质成长新增稳定来源：习舞奏乐固定 `乐理+2 气质+3 容貌+3`，御花园闲逛固定 `气质+3`，华清池温泉固定 `容貌+3`。
25. 杜娘新增稀有丹药池：冷香丸 `500` 气质 `+100`、驻颜丹 `500` 容貌 `+100`、延寿丹 `500` 寿命 `+5`、缠梦香 `1000` 且使目标每旬额外 `寿命-0.6`；每种物品每次刷新独立 `40%` 概率出现，单次库存不超过 `2`。
26. 玩家 `药理 > 80` 时可花费 `500` 自制缠梦香，每次 `70%` 概率成功。
27. 倾情 `>=80` 的妃子首次达标时会赠送冷香丸或驻颜丹其一；高宠爱妃子每月 `60%` 概率得皇帝赏赐，高太后好感妃子每月 `60%` 概率得太后赏赐；皇帝赏赐池中不出现延寿丹、缠梦香，太后赏赐池中不出现冷香丸、驻颜丹、延寿丹、缠梦香。
28. 若宫中任一被追踪角色自然寿命低于 `2` 年，玩家进入宝华殿礼佛时会收到一次“冥冥之音”式预警文本。
29. 项目现采用双 AI 结构：一个负责文本补全与剧情包装，一个负责按钮对话的关系倾向判定；两者都不得直接决定硬数值结果。
30. 即使完全关闭 AI，游戏也必须依靠模板文本、固定选项和本地关系标签完整跑通；普通对话导致的好感 / 倾情每旬每角色变化绝对值均不得超过 `5`。
31. 若玩家对某角色实施陷害或下毒并被对方确认或结案落地，则不走普通关系增减，而直接按事件轻中重将该角色对玩家的好感压至 `0 / -10 / -20`。
32. 旬末进入下一旬清晨时，体力不继承上一旬剩余值，而是按“新旬基础体力 + 状态修正”重新计算；当前无额外修正时固定回到 `10`。
33. 寝殿固定行动现采用明确数值表：诵读经典 / 泼墨作画 / 镂月裁云 / 调制香薰均为 `1` 时间格、`-1` 体力、对应技能 `+2`；习舞奏乐为 `1` 时间格、`-2` 体力、`乐理+2 气质+3 容貌+3`；请平安脉为 `1` 时间格、`0` 体力、`健康+3 压力-1`；殿内小酣为 `1` 时间格、`+3` 体力。

2.2 成长系统

核心逻辑：行动——属性——触发剧情——状态变化/获得物品

角色基本属性

声望（-2000~5000）口角，宴会才艺成功，侍寝成功，妃子美言或诋毁

宠爱（-100~100）依靠与皇帝的有效互动，皇帝心情，是否有其余妃子争宠

福德（-100~100）是否有陷害，造谣，下毒。礼佛会增加福德

野心（-100~100）取决于角色宫斗行为的频率与倾向性

心机（0~1000）心机越高，宫斗时胜算越大。他人下毒越容易发现

容貌（0~1000）可通过梳妆、保养、特殊剧情与高阶装扮提升

气质（0~1000）可通过读书，书画，乐理来增加

健康（0~1000）可通过服用补品来增加

压力（0~100）宫斗频率越高压力越大 玩家的压力值大于80会开始减寿命 每月减去0.2。*默认寿命为60岁~80岁之间开局随机寿命。寿命为隐藏值。可在玩家花钱算卦占卜时看见数字。

压力值来源于宫斗杀害的人太多，第一次杀人默认加20压力值，第二次10第三次5，大于3人后每次默认加5压力值，陷害或者造谣他人默认加3。

妃子压力值大于80会导致性情大变（包括但不限于野心值，心计值，性格由温柔变清冷等等的变化）并有概率疯癫。

系统补充规则（新增硬规则整理）

一、经济与银两

1. 玩家每月按位分领取月俸。若位分低于妃且宠爱低于20，则月俸固定克扣：

- 宠爱1~19：按70%发放
- 宠爱<=0：按50%发放
- 冷宫中：月俸为0

2. 若玩家宠爱>=61，则当月实际月俸+20%。

3. 每月最多2名倾情>60的妃子会将自己当月实际月俸的1/4赠送给玩家。该赠银总额允许高于玩家基础月俸。

4. 玩家每月固定结算宫务开销，按当月基础月俸 `W` 计算：

- 基础宫务 = `floor(W * 0.2)`
- 宠爱>=61时，高宠额外宫务 = `floor(W * 0.1)`

高宠额外宫务不得高于高宠额外收入，因此高宠路线始终为净收益。

5. 银两的大额消耗池需要常驻系统，包括：

- 朝臣打点
- 家族谋划
- 子嗣养育与礼仪
- 稀有礼物与补品
- 宫务整饬
- 宫斗案件运作

6. 政治与银两挂钩：

- 政治<20：不可正式朝臣打点
- 政治20~39：180银两=朝臣支持+2，320银两=+4
- 政治40~59：180银两=+3，320银两=+5，500银两=+8
- 政治60+：180银两=+3，320银两=+6，500银两=+10

7. 家族谋划当前按季度结算，仅保留第一档：120 银两。

二、旁观案件的银两干预

1. 若宫中发生调查案件且与玩家无直接嫌疑关系，则纪事中显示其他妃子的嫌疑值。

2. 玩家可花费 20 银两对某名嫌疑人进行一次干预：

- 20银两：嫌疑值 -5
- 20银两：嫌疑值 +5

3. 该操作可重复执行，直到案件结案或玩家银两不足。

4. 若压低交好妃子的嫌疑，则该妃子好感提高。若提高交恶妃子的嫌疑，则其后续定罪时玩家获得小幅声望收益。

三、偷情线与双父字段

1. 若玩家偷情后怀孕，系统仍在公开层面登记为皇帝之子。

2. 皇嗣记录需要额外保留：

- publicFatherId：公开父亲
- biologicalFatherId：真实生父
- isSecretLineage：是否为秘密血脉

3. 默认显示时只展示公开血脉；后续若触发“父子相认”剧情，再读取真实生父字段。

四、皇嗣养育消耗

1. 每名已出生子嗣每月固定消耗：

- 0~35月：每月20
- 36月及以上：每月35

2. 子嗣礼仪支出：

- 满月礼：180
- 周岁礼：260
- 两岁礼：320

3. 子嗣满3岁后可进入重华宫教育；若由卢安平辅导，则每季度每名孩子额外消耗120，且每季度最多辅导3名孩子。
